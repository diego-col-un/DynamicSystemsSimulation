# Material de referencia

Coloca aquí archivos `.txt` con el material autorizado que debe consultar la IA.

El backend divide cada archivo en fragmentos y recupera los que comparten términos con el modelo y sus ecuaciones. Es una primera versión de RAG local, sin subir el libro completo al navegador.

Ejemplo:

```text
knowledge/dinamica-sistemas.txt
```

Usa texto UTF-8. No incluyas libros protegidos por derechos de autor si no tienes permiso para redistribuirlos en el repositorio.
